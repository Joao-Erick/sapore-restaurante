# 🍝 Sapore | Restaurante & Gastronomia

Website responsivo de um restaurante italiano fictício, desenvolvido com **HTML, CSS e JavaScript**.

O projeto foi criado para demonstrar habilidades em desenvolvimento web, construção de interfaces modernas, responsividade e implementação de funcionalidades interativas.

## 🌐 Acesse o projeto

**[Visualizar o Sapore online](https://joao-erick.github.io/sapore-restaurante/)**

## ✨ Funcionalidades

- Layout responsivo para computadores, tablets e celulares.
- Menu de navegação adaptado para dispositivos móveis.
- Página inicial com apresentação do restaurante.
- Seção institucional "Sobre nós".
- Cardápio dinâmico com filtros por categoria.
- Exibição de pratos, descrições, imagens e preços.
- Formulário demonstrativo de reservas com validação de dados.
- Navegação suave entre as seções.
- Seção de contato e informações do restaurante.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** interatividade, filtros do cardápio e validação do formulário.
- **Git e GitHub:** versionamento e armazenamento do projeto.
- **GitHub Pages:** publicação gratuita do website.

## 📱 Responsividade

O Sapore foi desenvolvido para proporcionar uma experiência de navegação adaptada a diferentes tamanhos de tela.

Em dispositivos móveis, o menu tradicional é substituído por um menu hambúrguer, tornando a navegação mais prática e organizada.

## 📌 Sobre o projeto

O Sapore é um **projeto fictício desenvolvido exclusivamente para fins de estudo e portfólio profissional**.

O formulário de reservas realiza apenas uma simulação de validação dos dados. Nenhuma reserva real é efetuada ou enviada.
